# 15 Backend Practice Questions

A hands-on collection of backend development practice questions designed to strengthen my understanding of backend concepts through implementation.

This repository documents my learning journey as I explore how backend systems work, solve practical problems, and build a stronger foundation in server-side development.

## Topics Covered

The questions cover a range of backend development concepts, including:

- **Node.js:** Core modules, file system, events, and asynchronous programming.
- **Express.js:** Routing, middleware, request handling, and REST APIs.
- **HTTP:** HTTP methods, status codes, headers, and request-response lifecycle.
- **Prisma:** Database operations, ORM concepts, and query handling.
- **Authentication & Authorization:** User authentication, password hashing, JWT, and access control.
- **WebSockets:** Real-time, bidirectional communication.
- **Backend Fundamentals:** Error handling, API design, and other essential concepts.
